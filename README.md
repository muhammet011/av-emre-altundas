# Av. Emre Altundaş Hukuk Bürosu

Avukatlık ve hukuki danışmanlık sitesi.

## Yönetici paneli

`/admin` adresi şifre ile korunur. Şifre **kodun içinde değildir.**

Yayınlarken hosting panelinde (Vercel Environment Variables) şunu tanımlayın:

```
ADMIN_PASSWORD=sizin-sifreniz
```

Yerelde denemek için aynı değişkeni kabuk ortamında verin; `.env` dosyasını repoya eklemeyin.
